NeuroSpec

Портативная программа для просмотра характеристик компьютера

Скачать NeuroSpec для Windows

Один .exe-файл, 64-бит, установка не требуется

Полная информация

ОС, процессор, ОЗУ, видеокарта, материнская плата, BIOS, накопители (с типом SSD/HDD), сеть и мониторы.

Экспорт в один клик

Текст в буфер обмена, картинка или файл .txt/.json — выберите удобный формат для отправки.

Не требует установки и прав администратора. Скачали — и сразу пользуетесь.
