NeuroSpec — портативное приложение для просмотра характеристик компьютера
============================================================================

СОДЕРЖИМОЕ ПАПКИ
-----------------
NeuroSpec.csproj        — файл проекта
Program.cs               — точка входа приложения
MainForm.cs               — графический интерфейс (тёмная тема)
SystemSpecs.cs            — модель данных о системе
SystemInfoCollector.cs    — сбор характеристик через WMI
build.bat                 — скрипт автоматической сборки .exe


ШАГ 1. Установите .NET 8 SDK (один раз, только для сборки)
-------------------------------------------------------------
Скачайте и установите официальный .NET 8 SDK (бесплатно, от Microsoft):
https://dotnet.microsoft.com/download/dotnet/8.0

Выберите ".NET 8.0 SDK" (не "Runtime") для Windows, x64.
После установки откройте новое окно командной строки, чтобы команда
dotnet стала доступна.

Проверить установку: откройте командную строку (Win+R -> cmd) и введите:
    dotnet --version
Должна появиться версия вида 8.0.xxx.


ШАГ 2. Соберите приложение
------------------------------
Вариант А (просто, рекомендуется):
  Дважды щёлкните файл build.bat в этой папке.
  Дождитесь надписи "ГОТОВО!". Интернет нужен только на этом шаге —
  чтобы один раз скачать служебный пакет System.Management.

Вариант Б (вручную, через командную строку):
  1. Откройте командную строку в этой папке (Shift + правый клик по
     пустому месту в папке -> "Открыть окно PowerShell здесь").
  2. Выполните команду:

  dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o dist


ШАГ 3. Готово!
-----------------
Готовый файл NeuroSpec.exe появится в папке dist.

Это полностью портативный файл: его можно переносить на флешке,
копировать на любой компьютер с Windows 10/11 (64-бит) и запускать
без какой-либо установки — просто двойным щелчком. Никаких
дополнительных программ (включая .NET) на целевом компьютере
устанавливать НЕ нужно — всё уже "зашито" внутрь .exe.

Размер файла: примерно 60-90 МБ. Это нормально — внутрь встроен весь
движок .NET, необходимый для работы программы на любом компьютере.

ВАЖНО: при первом запуске Windows SmartScreen может показать окно
"Windows защитила ваш компьютер" — это стандартная реакция на любой
новый .exe-файл без цифровой подписи, а не признак вируса. Нажмите
"Подробнее" -> "Выполнить в любом случае".


КАК ПОЛЬЗОВАТЬСЯ ПРИЛОЖЕНИЕМ
--------------------------------
1. Запустите NeuroSpec.exe.
2. Приложение автоматически соберёт данные о вашем компьютере
   (обычно 1-3 секунды).
3. На экране появятся: ОС, процессор, оперативная память,
   видеокарта, материнская плата и накопители.
4. Нажмите кнопку "Копировать", чтобы скопировать все характеристики
   в буфер обмена — затем вставьте их (Ctrl+V) в любой чат или документ.
5. Кнопка "Обновить" повторно собирает данные (полезно, если вы
   подключили или отключили какое-то оборудование).


ЕСЛИ ЗАХОТИТЕ ДОБАВИТЬ СВОЮ ИКОНКУ
---------------------------------------
Поместите файл icon.ico рядом с NeuroSpec.csproj и добавьте в файл
NeuroSpec.csproj внутрь тега <PropertyGroup> строку:
    <ApplicationIcon>icon.ico</ApplicationIcon>
После этого пересоберите проект (build.bat).
